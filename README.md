# Weaver's Paradise: Emote Bending

Клиентский аддон для **NeoForge 1.21.1**, который связывает два мода:

- [Weaver's Paradise](https://modrinth.com/mod/weavers-paradise) — шитьё и ношение одежды;
- [Emotecraft](https://modrinth.com/mod/emotecraft) — эмоции и анимации игрока.

Без аддона эмоции сгибают руки, ноги и торс игрока в суставах, а одежда остаётся прямой. Рукав
торчит, пока рука согнута в локте, а штанина висит отдельно от согнутого колена. С аддоном одежда
сгибается вместе с телом.

## Что меняется

| Одежда | Что сгибается |
|---|---|
| Футболки, майки, жилеты, рубашки, лонгсливы, свитера, пончо, кроп-топы | торс в пояснице, рукава в локтях |
| Штаны (хлопок, шёлк, шерсть, джинсы) | колени и пояс |
| Гольфы | колени |
| Митенки и кожаные перчатки | локти |
| Юбка | не сгибается, но больше не улетает вслед за наклоном груди |

Ещё несколько исправлений:

- Когда эмоция наклоняет торс, штаны, гольфы и юбка остаются на ногах. Раньше Emotecraft
  поворачивал их вместе с грудью.
- Рукава поворачиваются вместе с плечами, как настоящие руки игрока.
- Одежда в слотах **Curios** ведёт себя так же, как одежда в обычных слотах брони.
- Надпись на груди футболки наклоняется вместе с торсом.
- Шапки, чокеры, кольца и другие аксессуары работают как раньше.

## Установка

Положите jar-файл в папку `mods` рядом с этими модами:

- Weaver's Paradise 1.6 или новее (и его зависимости: Curios, VortyLib);
- Emotecraft 2.4.x для 1.21.1. Библиотеки playerAnimator и bendy-lib идут внутри него.

Аддон нужен **только на клиенте**. Серверу и другим игрокам он не нужен: каждый видит изгиб
одежды у себя, если аддон стоит у него.

## Как это работает

Emotecraft 2.4.x для 1.21.1 двигает модель игрока через **playerAnimator**, а сгибает её через
**bendy-lib**: изгиб работает только у тех кубов модели, на которых он зарегистрирован. Модели одежды
Weaver's Paradise копируют позу с модели игрока, но изгиба на их кубах не было, поэтому они
оставались прямыми. Кроме того, playerAnimator целиком поворачивает с наклоном торса любой
дополнительный слой рендера, в том числе слой Curios.

Аддон состоит только из клиентских миксинов:

- на кубах моделей одежды регистрируется такой же изгиб, как на соответствующих частях тела игрока;
  после этого стандартный `copyFrom` сам переносит изгиб локтя, колена и поясницы;
- слои одежды помечаются как «нижние», как это делает сам playerAnimator для брони;
  рукава поворачиваются вместе с плечами отдельно;
- в рендерерах одежды для Curios снимается лишний поворот, который playerAnimator добавил ко
  всему слою Curios.

## Сборка

```
./gradlew build
```

Готовый jar появится в `build/libs/`.

Для `./gradlew runClient` положите в папку `run-mods/` jar-файлы Weaver's Paradise, VortyLib,
Curios, Emotecraft и playerAnimator. В git эта папка не попадает.
